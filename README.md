# Zap

The website of [Zap](https://zap.a3lab.ai), a native WhatsApp app for macOS
by A3 Direct Solutions LLP, and the home of its signed releases.

- `index.html`, `style.css`, `assets/`: the static site, served by
  Cloudflare Pages at zap.a3lab.ai (`bunx wrangler pages deploy . --project-name zap-a3lab`).
- [Releases](https://github.com/A3-Media/zap/releases): the signed and
  notarized `Zap.dmg`. The site links to `releases/latest/download/Zap.dmg`.

Zap is an unofficial client and is not affiliated with WhatsApp or Meta.
