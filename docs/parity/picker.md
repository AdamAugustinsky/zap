# Parity: ui/picker

`docs/PARITY.md` holds the status of record for every row; this file holds the evidence (tests, captures, hand steps and notes).

Rows of `docs/PARITY.md` whose Go owner is `ui/picker` (PK-001…PK-017, MM-003, DM-008), swept against upstream `src/ui/picker.rs` and `gnui/ui/picker` at `z3-picker`. `docs/PARITY.md` itself is not edited. Tests are in `gnui/ui/picker` and run on the fake core with `widgettest` (by role and name); the `TestDemo*` ones drive the picker against the live demo core (skipped without the library and with -short). Where a row's Verify column says `capture`, no shot of upstream's `--demo-shot` was compared (the Rust app is not built here); the behaviour is covered by the tests and the layout was checked in offscreen renders (`PICKER_SHOT=dir go test -run TestShots ./ui/picker`) and once live (dark, emoji tab).
