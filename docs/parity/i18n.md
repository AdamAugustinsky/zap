Added as one marked block at the end of the pot and each `.po` (sorted by msgid, `#:` references pointing at `gnui/`), so a later extraction from the Rust source merges around it. Some are identical to the English (e.g. "GIF", "Pidgin", "Info" in German), which is a translation, not a fallback.

Terminology follows each catalog's own: French "discussion", Portuguese "conversa" (locked: "trancada"), Indonesian "chat" (locked: "obrolan terkunci", as the catalog has it), Italian feminine "chat", Traditional Chinese "對話", Simplified "聊天"; the Locked tab, Calls, Starred, stickers, tray, "Linked devices" and "System Settings / Login Items" words are the ones the catalogs and macOS use. Register is each file's: du (de, es, it, zh-Hans), vous/siz/Anda/você/вы/您 (fr, tr, id, pt-BR, ru, zh-Hant). "Enter Full Screen" and "Exit Full Screen" are Apple's own wording, read from this machine's `AppKit.framework` `MenuCommands.loctable`: de "Vollbildmodus" / "Vollbildmodus aus", es "Usar pantalla completa" / "Salir de pantalla completa", fr "Activer le mode plein écran" / "Quitter le mode plein écran", id "Masuk ke Layar Penuh" / "Keluar dari Layar Penuh", it "Attiva modalità a tutto schermo" / "Disattiva modalità a tutto schermo", pt-BR "Entrar em Tela Cheia" / "Sair da Tela Cheia", ru "Перейти в полноэкранный режим" / "Выйти из полноэкранного режима", tr "Tam Ekrana Geç" / "Tam Ekrandan Çık", zh-Hans "进入全屏幕" / "退出全屏幕", zh-Hant "進入全螢幕" / "離開全螢幕".

Three strings carry a count in a single `T` call, so the Go side picks no plural form for them: "{} selected", "{} unread messages" and "{} unread messages, mentioned you". Where a language agrees the noun with the number (Russian, German, French, …), they are worded so the number needs no agreement ("Выбрано: {}", "Непрочитанных сообщений: {}").

### Round 2: English that skipped `i18n`, now wrapped

A `go/types` scan of every non-test file under `gnui/` (call arguments by callee and parameter, then every string literal) found text that reached the screen or a screen reader without `i18n`. 111 call sites were wrapped (`T`, `P` or a `Format` pattern); 15 of them (Busy, Photo, Video, Audio, Location, Live location (ended), Voice call, Missed video/voice call, Video call, Recent, Loading chat history) use msgids upstream's pot already had, so they come translated. 74 msgids are new (the second marked block, plus two update refusals added after merging origin/gnui; `errTooLarge` is now a comparable `refusal{}` whose `Error()` translates when shown; at the end of the pot and of every `.po`), translated in all 10 catalogs. The About paragraph now says "written in Go with gonativeui" (shape unchanged, "whatsapp-rust" kept; the author credit line with its link to paolino.me is untouched), and `ui/dialogs/rows_test.go` follows it.

- Refusals and reasons: `ui/settings/updater.go` (5 refusals, "the update feed answered {status}"), `ui/settings/controls2.go` (4 proxy messages), `ui/composer/voice.go` (3 microphone reasons), `state/events.go` ("History loaded", "Back online"), `ui/accounts/acct/acct.go` ("Could not add an account"; `ErrCannotAdd` stays the English constant).
- Composed: "Only {admins} can send messages" is one pattern, split around `{admins}` at draw time so the word stays in the accent colour; "Requesting a code for +{phone}…" and "for +{phone}" likewise; the banner's "ZapFast {version} is available" and "Offline ({reason}). Reconnecting…" are patterns. "Loading chat history" reuses upstream's msgid with "…" and the percentage appended in code.
- Theme names Follow system, Light, Dark are translated; "Messages" is the theme's own name and stays.
- Message info summaries (`ui/msginfo`): Photo, Video, GIF, Document: {name}, Sticker pack: {name}, Location: {name}, Contact: {name}, Poll: {question}, View once …, Unsupported message ({what}), call labels.
- Emoji group names (`groupName`), "Frequently Used", "Nothing matches"; picker and its tabs; banner buttons Retry/Update; rail tooltips ("Settings"/"Close settings" + the shortcut); "Select a chat on the left.", "Your chats appear…", "Open a chat first", "Copy this message", the previous/next-chat menu titles.
- Accessible names (spinner, list, scroll, field, popover, splitter): the display part is translated and a stable `###id` follows, so keys do not change with the language. Where a name is also used as a lookup (`Description text`) both sites use the same call.
- `labelmgr.go:154` now `P("label colour", "Colour")`. `rows.go:469/471` keep their wording: the pot has no plural for the "mentioned you" variant.
- Left English on purpose: the macOS menu bar titles in `ui/shell/menu.go` (upstream's menu is untranslated and the menu model is built once at start, so a language change would not reach it); clipboard summaries in `ui/conversation/copy.go` (not UI); the "Unknown" sentinel (compared by value in `ui/info`, `ui/composer`, `model`); `Messages`/`Toolbar`/`Rail`-style names that are identity keys only; logs, flags, CLI text.

### Round 3: the conversation pane, the language switch, the menu bar

34 new msgids (a third marked block at the end of the pot and of every `.po`), translated in all 10 catalogs. Every msgid in use (901) is translated except `ZapFast`.

- **`ui/conversation`:** `copy.go`'s summaries (`summaryOf`: Photo … Voice call, with `{name}`, `{question}`, `{what}` patterns; the clipboard markers and "(replying to " stay English), `extras.go` ("{names} and {last} are typing…", "React to your message", "React to {name}'s message"), `footer.go` (Not sent and its hint, translated where shown), `kinds` (`Loading` spinners, Carousel), `search.go` (kind words, Search results), `av/clip.go` (GIF). "Unknown" stays.
- **Message field:** `rexui.Composer(P("message field", "Message")+"###message")`. Upstream's accessible label is the untranslated "Message" (`zf:src/ui/conversation.rs:1727`); the existing msgid "Message" is the verb ("Send message"), so the noun has its own context.
- **Theme pop-up:** `themeList.poll` rebuilds the four built-in names when the settings texts' language moved (`tx.loc`).
- **Tray menu and notification actions:** left as built at launch. Upstream does not rebuild them: its tray items are untranslated English literals (`zf:src/app.rs:1088`), and its notification category is registered once. They are built after startup applied the language, so they follow the saved or system language at launch, not a later switch.
- **Menu bar:** `ui/shell/menu.go` titles use context `menu bar`, in Apple's wording (AppKit `MenuCommands.loctable`: Settings…, Cut/Copy/Paste/Select All, Minimize, Close Window, File, View, Window, Help, Enter Full Screen; Preview's `MainMenu.loctable`: Undo, Redo, Find…, Edit, Zoom, Zoom In/Out, Actual Size, About/Quit patterns with the app name). ZapFast's own items (New Chat…, Show ZapFast, Keyboard Shortcuts, ZapFast Help, Toggle Sidebar) follow the catalogs' terms. The framework replaces the model at runtime (`App.SetMenu`, `Kit.SetMenu`): `Shell.RefreshMenus` rebuilds both models when `i18n.Current()` changed, and every window picks the new one up at its next frame (`screen.SyncMenu`). The application menu's About, Quit, Hide ZapFast, Hide Others and Show All use translated role-command titles; Services uses the translated `menu.MenuServices` title. "Exit Full Screen" is AppKit's own retitling, in the system language. The ellipsis is "…" in zh-Hant too (Apple uses "⋯"), as the rest of that catalog.
- **Settings window title:** `Screen.retitle` calls `Win.SetTitle` once when the language changed.
- **Not done:** `cmd/zapfast/tour.go` and `whatsnew.go` (the integrator's).

### Round 4: the completeness test, ellipses, the application menu

- **`gnui/i18n/complete_test.go`** (`TestEveryMessageOfTheCodeIsTranslated`, 0.1 s, `go/parser` only): collects the literals and string constants (and concatenations) passed to `i18n.T/P/N/TIn/PIn/NIn`, to names bound to them (`T := i18n.T`) and to one-line wrappers (`tr`); requires each in `zapfast.pot`, a non-empty, non-fuzzy `msgstr` (every plural form) in all 10 catalogs, and the same `{placeholders}`. 22 calls whose message is built at run time (the settings row tables, the shortcut list) are not seen. The application-menu messages are now used directly in the code, so they need no `plannedMessages` exception.
- **New msgids (fourth block):** the updater's two refusals; "Loading chat history…" and "Loading chat history… {percent}%" (the ellipsis was appended in code, out of reach of the language's spacing rule); "ZapFast" (the product name, translated as itself, which the test requires); the menu bar's "Hide ZapFast", "Hide Others", "Show All", "Services".
- **Ellipsis:** Apple's German puts a no-break space before "…" ("Einstellungen\u00a0…", AppKit `MenuCommands.loctable`: 102 of 124 ellipses in AppKit's and Preview's German strings; the plain-space ones are in the Apple menu and Preview's scanner items). Every German msgstr now uses U+00A0 + "…". Es, fr, id, it, pt-BR, ru, tr and zh-Hans put none before it, as Apple's do. Apple's zh-Hant writes "⋯" (U+22EF) in every ellipsis (145 of 145; "設定⋯"), so zh-Hant's msgstrs use it.
- **Application menu:** Apple's wording, from Preview's `MainMenu.loctable` (Hide, About, Quit with the app name; Hide Others) and AppKit's `Common.loctable` / `Services.loctable` (Show All, Services). The msgids stay literal with the app name, as "About ZapFast" and "Quit ZapFast" are; context `menu bar`. pt-BR's Quit is "Encerrar ZapFast" (Apple has no article there).

### Round 5: the history banner's allocation, the tables

- **Banner:** the percentage is appended with `Fmt.Int` through `fillInt`, not a string (`strconv.Itoa(100)` allocated). `TestTheHistoryBannerAllocatesNothing` (`cmd/zapfast/alloc_test.go`) shows the banner at 100 % and needs 0 allocations per frame.
- **Tables in the completeness test:** `tableSpecs` in `gnui/i18n/complete_test.go` says where each table's source strings are (a variable's literals, the literals assigned to a name in a function, the literal arguments of a call, a struct field, the settings' `tx{}`/`m()` values), 10 specs, 97 more messages checked, no test hooks in production code. A spec that finds nothing, or a run-time message in a file no spec covers, fails the test. Not checkable, named in the test: the core's error text (`state/events.go:72`) and the number-lookup failure (`ui/dialogs/newchat.go:334`).
- The new coverage found nothing untranslated.
